# F14 — Hugging Face Spaces Deployment

## Purpose

Deploy the full AttentionX MVP to a public Hugging Face Space so that judges and
users can access the app from a browser without local installation.

## Target Environment

| Resource    | Value              |
|-------------|--------------------|
| Host        | Hugging Face Spaces |
| Hardware    | CPU Basic (free tier) |
| RAM         | 16 GB              |
| CPU Cores   | 2                  |
| Disk        | 50 GB ephemeral    |
| Persistence | None (ephemeral)   |
| Public URL  | Yes (auto-generated by HF) |

## Required Files for Deployment

| File             | Purpose                                              |
|------------------|------------------------------------------------------|
| `app.py`         | Gradio entrypoint (must be named `app.py` for Spaces) |
| `requirements.txt` | Python dependencies                               |
| `packages.txt`   | System-level apt packages (must include `ffmpeg`)  |
| `README.md`      | Space metadata and description (YAML frontmatter)  |

## README.md Frontmatter (HF Spaces Metadata)

```yaml
---
title: AttentionX
emoji: 🎬
colorFrom: blue
colorTo: purple
sdk: gradio
sdk_version: "4.x"
app_file: app.py
pinned: false
---
```

## packages.txt Content

```
ffmpeg
```

This installs FFmpeg at the system level via apt on Spaces startup.

## requirements.txt Essentials

```
gradio>=4.0
faster-whisper>=1.0
librosa>=0.10
mediapipe>=0.10
scenedetect[opencv]>=0.6
opencv-python-headless>=4.8
numpy>=1.24
scipy>=1.11
google-generativeai>=0.5
```

Note: `google-generativeai` is included but the feature is gated by env var,
so it is safe to install even when not actively used.

## Deployment Steps

1. Create a new Hugging Face Space (SDK: Gradio).
2. Push this repository to the Space's git remote.
3. Verify Space build log completes without error.
4. Open the public URL and run the full user flow.
5. Optionally: add `GEMINI_API_KEY` as a Space secret (not a public env var).

## RAM Budget Verification

Expected working set during processing:
- faster-whisper "base" model: ~150 MB
- librosa + numpy audio array for 10-min video: ~500 MB
- MediaPipe face detector: ~50 MB
- FFmpeg subprocess: ~100 MB
- Total peak estimate: ~1 GB

This is well within the 16 GB RAM available on the free CPU tier.

## Constraints

- `app.py` must be the entrypoint (HF Spaces requirement for Gradio SDK).
- All file writes must go to `data/temp/` or `data/outputs/` — these are ephemeral.
- Do not write to the repository root or any path outside the working directory.
- No GPU is assumed; all processing must work on CPU.
- Secrets (API keys) must be set via HF Space secrets UI, not committed to the repo.
